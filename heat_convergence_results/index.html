    热传导方程收敛性测试结果

    测试日期

    2025年10月22日

    测试配置

    物理参数

    • 热扩散系数: α = 0.1
    • 最终时间: T = 0.05
    • 初始条件: u(x,y,0) = sin(πx)sin(πy)
    • 边界条件: u = 0 (齐次Dirichlet)

    精确解

    \[u(x,y,t) = e^{-2\pi^2\alpha t} \sin(\pi x) \sin(\pi y)\]

    数值方法

    • 时间离散: 隐式欧拉法（一阶时间，无条件稳定）
    • 空间离散: 五点差分格式（二阶空间）
    • 线性求解器: 红黑Gauss-Seidel迭代
    • 边界处理: 虚拟单元法（u_ghost = -u_interior）

    收敛性测试结果

    1. 空间-时间耦合收敛性测试

    使用时间步长 \(\Delta t \propto h^2\) 来平衡空间和时间误差：

    网格大小 h (网格间距) dt (时间步长) L2误差 收敛率
    16×16 0.0625 0.00039062 1.617×10⁻⁴ ---
    32×32 0.03125 0.00009765 4.027×10⁻⁵ 2.006
    64×64 0.015625 0.00002441 1.006×10⁻⁵ 2.001
    128×128 0.0078125 0.00000610 2.516×10⁻⁶ 2.000

    结论: ✅ 实现了二阶收敛！收敛率约为2.0。

    2. 收敛率计算

    收敛率定义为： $\(r = \frac{\log(E_{h} / E_{h/2})}{\log(2)}\)$

    其中 \(E_h\) 是网格间距为 \(h\) 时的误差。

    • 16→32: 收敛率 = 2.006
    • 32→64: 收敛率 = 2.001
    • 64→128: 收敛率 = 2.000

    平均收敛率: 2.002 （非常接近理论值2.0）

    3. 误差减小因子

    网格加密 误差减小因子 理论值 (2²)
    16→32 4.01 4.0
    32→64 4.00 4.0
    64→128 4.00 4.0

    结论: 网格加密2倍，误差减小4倍，符合二阶方法的预期。

    计算效率

    Gauss-Seidel 迭代次数

    对于收敛容差 \(10^{-8}\)：

    网格大小 每时间步平均迭代次数
    32×32 7
    64×64 10
    128×128 14

    观察: 迭代次数随网格加密缓慢增长，说明Gauss-Seidel对这个问题效率较高。

    并行性能

    • 测试使用 4 个 MPI 进程
    • 所有测试均成功完成，无死锁或数据竞争
    • 边界处理使用安全的neighbor getter函数，避免了race condition

    理论分析

    离散化误差

    对于隐式欧拉+五点差分格式：

    空间误差: \(O(h^2)\) （五点差分格式）

    时间误差: \(O(\Delta t)\) （隐式欧拉）

    总误差: 当 \(\Delta t \propto h^2\) 时， $\(\|u - u_h\|_{L^2} = O(h^2 + \Delta t) = O(h^2)\)$

    因此期望看到二阶收敛，这与实验结果一致。

    虚拟单元边界条件

    对于单元中心网格，物理边界上没有网格点。使用虚拟单元法：

    \[u_{-1,j} = -u_{0,j}\]

    使得在边界面上： $\(u_{\text{face}} = \frac{u_{-1,j} + u_{0,j}}{2} = 0\)$

    这种方法保持了二阶精度。

    数值稳定性

    隐式方法的优势

    隐式欧拉法是无条件稳定的，不受CFL条件限制：

    显式方法稳定性条件: $\(\Delta t \leq \frac{h^2}{4\alpha}\)$

    对于 \(h = 0.015625, \alpha = 0.1\): $\(\Delta t_{\max}^{\text{explicit}} = 6.1 \times 10^{-4}\)$

    而我们使用的 \(\Delta t = 2.44 \times 10^{-5}\) 远小于此限制（为了精度而非稳定性）。

    实现验证

    代码正确性指标

    1. ✅ 质量守恒: 总质量（积分）随时间按指数衰减（符合精确解）
    2. ✅ 边界条件: 所有边界点严格满足 u = 0
    3. ✅ 残差收敛: 每步线性求解残差降至 \(10^{-8}\) 以下
    4. ✅ 并行一致性: 4进程结果与1进程结果一致（在机器精度内）
    5. ✅ 收敛阶数: 实测收敛率 2.002 ≈ 理论值 2.0

    关键实现细节

    1. 网格间距计算: h = 1.0 / N （使用实际全局网格大小）
    2. L2范数计算: ||·||_L2 = sqrt(h²) * ||·||_l2 （连续范数）
    3. 边界处理: DMStag_Get* 安全读取函数
    4. 红黑排序: ((ex + ey) & 1) 确保正确的棋盘更新

    推荐使用参数

    对于不同网格大小，推荐的时间步长：

    网格 推荐 dt 用途
    32×32 0.0001 快速测试
    64×64 0.00005 标准模拟
    128×128 0.00001 高精度
    256×256 0.000005 生产计算

    结论

    热传导方程求解器已通过严格的收敛性验证：

    1. 实现了理论预期的二阶空间精度
    2. 隐式时间积分无条件稳定
    3. Gauss-Seidel迭代快速收敛（每步7-14次迭代）
    4. 虚拟单元边界条件正确实施
    5. 并行实现无竞争条件

    该求解器可作为更复杂问题（反应扩散、Navier-Stokes等）的可靠基础。
