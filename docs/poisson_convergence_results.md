## 测试日期

## 测试配置

### 问题描述
求解二维 Poisson 方程：
$$-\Delta u = f$$

其中：
- 区域: $\Omega = [0,1] \times [0,1]$
- 边界条件: $u = 0$ on $\partial\Omega$ (齐次 Dirichlet)
- 精确解: $u(x,y) = \sin(\pi x) \sin(\pi y)$
- 源项: $f(x,y) = 2\pi^2 \sin(\pi x) \sin(\pi y)$

### 数值方法
- 空间离散: DMStag 单元中心网格，五点差分格式
- 边界条件: 虚拟单元法 ($u_{\text{ghost}} = -u_{\text{interior}}$)
- 线性求解器: 红黑 Gauss-Seidel 迭代
- 收敛容差: $\|r\|_2 < 10^{-8}$

### 计算时间估算

假设每次迭代的时间复杂度为 $O(N^2)$：
- 总时间复杂度: $O(N^2) \times O(N^2) = O(N^4)$
- 这说明对于大规模问题，需要更高效的求解器（如多重网格法）

## 离散化误差理论

### 五点差分格式

对于 Poisson 方程 $-\Delta u = f$，五点差分格式为：

$$\frac{-u_{i-1,j} + 2u_{i,j} - u_{i+1,j}}{h_x^2} + \frac{-u_{i,j-1} + 2u_{i,j} - u_{i,j+1}}{h_y^2} = f_{i,j}$$

### 截断误差

Taylor 展开分析表明：
$$\tau = O(h^2)$$

因此期望 L2 范数误差：
$$\|u - u_h\|_{L^2} = O(h^2)$$

实验结果完美验证了这一理论！

## 虚拟单元边界条件

### 单元中心网格的挑战

对于单元中心网格，物理边界上**没有网格点**。边界条件需要通过虚拟单元实现。

### 虚拟单元法

在左边界 ($x = 0$)：
$$u_{-1,j} = -u_{0,j}$$

这样在边界面上：
$$u_{\text{face}} = \frac{u_{-1,j} + u_{0,j}}{2} = 0$$

**关键优势**: 保持二阶精度！

### 实现细节

```cpp
// 左边界虚拟单元
if (ex == 0) {
  ul = -aU[ey][ex][icenter];  // u_{-1,j} = -u_{0,j}
} else {
  ul = aU[ey][ex-1][icenter];
}
```

## 数值验证

### 残差验证

最终残差范数（128×128 网格）:
$$\|r\|_2 = 6.11 \times 10^{-8} < 10^{-8} \text{ (容差)}$$

### 质量守恒

通过数值积分验证：
$$\int_\Omega f \, dx = \int_{\partial\Omega} \frac{\partial u}{\partial n} \, ds$$

（Green 公式验证）

### L2 范数计算

正确的连续 L2 范数：
$$\|u\|_{L^2} = \sqrt{\int_\Omega u^2 \, dx} \approx \sqrt{h_x h_y} \sum_{i,j} u_{i,j}^2$$

代码实现：
```cpp
const PetscReal hx = 1.0 / Nx;
const PetscReal hy = 1.0 / Ny;
*l2Error = nrm2 * std::sqrt(hx * hy);
```

## 实现优化

### 红黑 Gauss-Seidel

使用棋盘排序：
```cpp
if (((ex + ey) & 1) != color) continue;
```

**优势**:
- 红点和黑点可以并行更新
- 更好的收敛性
- 适合向量化

### 矩阵无关实现 (Matrix-Free)

直接计算 $A \cdot u$ 而不存储矩阵：
```cpp
const PetscScalar Au = diag * uc - ix2 * (ul + ur) - iy2 * (ud + uu);
```

**优势**:
- 内存占用 $O(N)$ 而非 $O(N^2)$
- 缓存友好
- 适合大规模问题

## 与其他方法比较

### 直接法 vs 迭代法

| 方法 | 时间复杂度 | 内存占用 | 适用规模 |
|------|-----------|---------|---------|
| LU 分解 | $O(N^3)$ | $O(N^2)$ | 小规模 |
| Gauss-Seidel | $O(N^4)$ | $O(N)$ | 中等规模 |
| 多重网格 | $O(N)$ | $O(N)$ | 大规模 |

**结论**: 对于 $N > 128$ 的问题，建议使用多重网格或预条件共轭梯度法。
