# 功能规范：泊松方程单元测试

**功能分支**: `002-poisson-unit-tests`  
**创建日期**: 2025-10-23  
**状态**: 草稿  
**输入**: 用户描述："基于 src/poisson_DMStag_2D.cpp 的泊松方程单元测试"

## 用户场景与测试（必需）

### 用户故事 1 - 本地运行泊松测试（优先级：P1）

作为开发人员，我可以使用单个命令运行泊松单元测试并获得清晰的摘要，以便快速验证更改。

**优先级理由**：确保在修改核心椭圆例程时获得快速、可靠的反馈。

**独立测试**：运行测试入口点仅执行泊松测试并打印通过/失败计数；除项目标准外无需额外设置。

**验收场景**：

1. 给定一个干净的检出，当开发人员运行测试入口点时，所有泊松测试执行并打印通过/失败计数的摘要。
2. 给定一个故意破坏模板恒等式的更改，当测试运行时，至少有一个测试失败并带有可操作的消息。

---

### 用户故事 2 - 验证算子一致性和收敛性（优先级：P1）

作为维护者，我可以验证离散算子一致性并在网格细化时观察预期的收敛性，从而信任数值基础。

**优先级理由**：算子正确性和收敛性对解的准确性至关重要。

**独立测试**：制造解测试在多个网格分辨率上计算误差并将观察到的阶数与预期速率进行比较；独立于其他测试通过。

**验收场景**：

1. 给定多个网格分辨率上的制造解，当计算误差时，观察到的速率在 10% 以内与预期阶数匹配。
2. 给定常数右侧和适当的边界条件，当计算解时，残差范数降至目标容差以下。

---

### 用户故事 3 - 边界条件验证（优先级：P2）

作为审查者，我可以确认实现遵守代表性面和角上的 Dirichlet 和 Neumann 边界条件，从而确保边缘行为正确。

**优先级理由**：边界处理错误通常导致微妙的不准确性。

**独立测试**：仅边界的测试夹具在容差内验证值/通量与预期。

**验收场景**：

1. 给定所有边上的 Dirichlet 边界条件，当求解器运行时，边界值在容差内与规定值匹配。
2. 给定选定边上的 Neumann 边界条件，当求解器运行时，法向通量在容差内与规定值匹配，并且在适用时解在常数范围内是唯一的。

### 边缘情况

- 齐次右侧与 Dirichlet 边界条件（零解）
- 常数右侧和混合边界条件（偏移/通量的完整性检查）
- 小域（2x2、3x3）以捕获索引/交错问题
- 压力/零空间类不变性（在适用的情况下常数偏移）
- 高度各向异性的网格间距（如果可配置）影响误差率

## 需求（必需）

### 范围边界

- 范围内：泊松方程的单元测试，涵盖离散算子恒等式、边界执行、求解器残差和使用制造解的网格细化收敛性。
- 范围外：完整的瞬态模拟、性能基准测试、可视化验证。

### 假设

- 仓库中提供现有的泊松实现。
- 确定性测试；通过显式容差处理可接受的数值方差。
- 最小域和规范边界集足以暴露缺陷。

### 功能需求

- FR-001：提供单个入口点以仅运行泊松单元测试并报告简洁摘要。
- FR-002：包括在最小网格上验证离散拉普拉斯/算子恒等式的测试。
- FR-003：包括使用制造解测量观察阶数与预期的网格细化测试。
- FR-004：在容差内验证代表性面/角上的 Dirichlet 和 Neumann 边界条件。
- FR-005：要求求解器残差范数在代表性右侧/边界条件设置上降至指定容差以下。
- FR-006：确保测试快速完成（在典型开发人员笔记本电脑上泊松子集的目标 ≤ 60 秒）。
- FR-007：确保测试在支持的环境中是确定性的，无需外部服务。
- FR-008：提供简要文档，描述如何运行泊松测试和解释失败。

### 验收标准

- AC-001（FR-001）：运行记录的命令仅执行泊松测试并打印反映通过/失败的退出状态的摘要。
- AC-002（FR-002）：算子恒等式测试以相对误差 ≤ 1e-8（或接近零范数的绝对误差 ≤ 1e-12）通过。
- AC-003（FR-003）：网格细化上的观察收敛率在制造解上与预期阶数在 10% 以内匹配。
- AC-004（FR-004）：边界条件测试在规定值/通量的 1e-8 相对误差内通过。
- AC-005（FR-005）：最小网格的代表性右侧/边界条件的求解器残差 L2 范数 ≤ 1e-10。
- AC-006（FR-006）：在审查期间，泊松子集测试运行时间在当代笔记本电脑上 ≤ 60 秒。
- AC-007（FR-007）：重新运行泊松测试三次在容差窗口内产生相同的通过/失败结果。
- AC-008（FR-008）：简短的 README 或文档部分解释运行泊松测试和诊断常见失败。

### 关键实体（如果涉及数据）

- 测试用例：具有域、右侧、边界条件规范和预期定量结果的最小场景。
- 参考解：用于计算预期结果和误差边界的制造表达式/恒等式。
- 配置：定义测试条件和容差的参数（域大小、边界类型）。

## 成功标准（必需）

### 可衡量的结果

- SC-001：开发人员可以在本地运行泊松测试并在 ≤ 60 秒内看到清晰的摘要。
- SC-002：算子一致性和收敛性属性通过测试验证，当不满足容差/阶数时失败。
- SC-003：在支持的平台上使用记录的过程连续三次运行中零间歇性失败。
- SC-004：审查者依靠套件检测回归；在审查期间捕获种子缺陷。
