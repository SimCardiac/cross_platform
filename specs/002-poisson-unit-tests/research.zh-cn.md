# 研究：泊松方程单元测试

## 决策

- 测试工具：使用与 CMake 集成的 CTest 进行简单编排；单个测试可以是 CLI 驱动的或使用小型 C++ 测试目标（除非 gtest 增加明显价值，否则最终选择可以仅使用 CTest）
- 制造解对（u_exact、f）：
  1) u(x,y) = x² + y² → f(x,y) = -4
  2) u(x,y) = sin(πx) sin(πy) → f(x,y) = 2π² sin(πx) sin(πy)
  3) u(x,y) = cos(πx) cos(πy) → f(x,y) = 2π² cos(πx) cos(πy)
- 仅 CLI 配置：所有参数（网格大小、对选择、边界条件类型、容差）通过命令行提供
- 构建流程：`source ~/.bashrc` → 通过 CMake + Make 进行源外构建
- 容差和目标：残差 L2 ≤ 1e-10；恒等式检查 ≤ 1e-8 相对（如果需要 ≤ 1e-12 绝对）；细化阶数在预期的 10% 以内

## 理由

- CTest 由 CMake 原生支持，降低集成摩擦并便于在 CI 上运行
- 选择的制造解是标准的、平滑的，并且同时练习多项式和三角行为
- 仅 CLI 输入在没有配置文件的情况下实现可重现性，匹配用户约束
- 源 ~/.bashrc 确保在配置之前 PETSc/MPI 环境变量可用

## 考虑的替代方案

- GoogleTest：更丰富的断言和测试结构；最初被拒绝以保持集成最小化；如果结构增长，可以稍后添加
- JSON 配置文件：根据仅命令行的要求被拒绝；可以在将来添加为可选覆盖
- 通过物理长度（Lx、Ly）和非均匀网格的域定义：推迟到以后的复杂性；从单位正方形和均匀网格开始
